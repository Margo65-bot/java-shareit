# 📦 ShareIt — сервис для аренды вещей

[![Java](https://img.shields.io/badge/Java-21%2B-orange)](https://www.oracle.com/java/)

**ShareIt** — это бэкенд-сервис для совместного использования вещей (шеринг). Проект решает проблему временного доступа к вещам: пользователи могут давать свои предметы в аренду, находить нужные вещи у других, бронировать их на определённые даты и оставлять отзывы после использования.

---

## 🌟 Какую проблему решает проект?

В повседневной жизни часто возникают ситуации, когда вещь нужна на короткий срок: дрель для ремонта, книга для чтения, спортивный инвентарь для поездки. Покупать новую вещь ради одноразового использования невыгодно. **ShareIt решает эту боль:**

- 🔄 **Даёт вещам вторую жизнь** — владельцы могут зарабатывать на простаивающих вещах
- 💰 **Экономит бюджет** — арендаторам не нужно покупать вещи для временного использования
- 🤝 **Создаёт сообщество** — люди помогают друг другу и делятся ресурсами

## 📊 Ключевые результаты

Проект разрабатывался с **поэтапным рефакторингом от монолита к микросервисам**. В результате создан полноценный бэкенд, который:

- ✅ **Обрабатывает 5 типов сущностей** (пользователи, вещи, бронирования, запросы, комментарии)
- ✅ **Поддерживает 20+ эндпоинтов** для работы с данными
- ✅ **Реализует полный цикл аренды** — от публикации вещи до отзыва после использования
- ✅ **Покрыт тестами** (модульные, интеграционные, тесты контроллеров)
- ✅ **Запускается в Docker-контейнерах** с разделением сервисов
